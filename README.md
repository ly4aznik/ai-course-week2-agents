## Запуск одной командой

Нужны Git, [uv](https://docs.astral.sh/uv/getting-started/installation/) и API-ключ OpenRouter. Клонируйте репозиторий и из его корня выполните:

```bash
uv run python check.py --n 3
```

uv создаст окружение Python 3.12+ и установит зависимости из `uv.lock`. Ключ вводится скрыто через `getpass`, в файлы не записывается. Настройки по умолчанию: OpenRouter, `openai/gpt-6-luna`, `reasoning_effort=none`.

Для конфигурации через файл скопируйте `.env.example` в `.env` и задайте `OPENROUTER_API_KEY`, `OPENAI_BASE_URL`, `MODEL`. `.env` и виртуальное окружение исключены из Git. Для другого OpenAI-совместимого провайдера используйте `OPENAI_API_KEY`; если цена модели недоступна в каталоге, задайте `PRICE_INPUT_PER_TOKEN` и `PRICE_OUTPUT_PER_TOKEN` в USD за токен. Выбранная модель должна поддерживать инструменты и используемые параметры запроса.

Команда выполняет десять задач по три раза для каждого варианта описаний и записывает новый каталог `runs/`, метрики и `week2/REPORT.md`. При нехватке трёх естественных неудач добавляются явно помеченные диагностики: недоступная база, повреждённые аргументы, повторяемое наблюдение. Они не входят в основные метрики. `--no-diagnostics` отключает их; `--max-steps` задаёт предел шагов (по умолчанию 6).

## Структура

| Путь | Содержимое |
|---|---|
| `assignment/tools.py` | Пять инструментов, схемы и два варианта описаний |
| `assignment/loop.py` | Ручной цикл, лимиты, ошибки как наблюдения, usage и JSONL |

| `check.py` | Исполнитель эксперимента |
| `runs/20261012T182559Z/` | Сохранённые настоящие траектории, цены и отпечатки кода/данных |

## Проверки и воспроизводимость

```bash
uv run python -m unittest test_assignment -v
```

Проверены схемы A/B, обработка ошибки и восстановление, лимит шагов, метрики, расписания и телефоны. Запуск в новом изолированном окружении uv также проверен. Подставные ответы используются только в инженерных тестах; все опубликованные экспериментальные траектории получены от настоящей модели.

Первоначальный оценщик отвергал 18 корректных ответов из-за эквивалентной записи часов и разделителей в телефонах. Исправление применено симметрично без повторных модельных запросов. Первые оценки сохранены в `records.v1.json`/`summary.v1.json` и JSONL; исправленные добавлены событиями `reevaluation`.

Пересчитать сохранённые ответы без API:

```bash
uv run python rescore.py runs/20261012T182559Z
```

`--diagnostics` разрешает дополнительные запросы для диагностических сценариев. Собрать PDF именно сохранённого эксперимента:

```bash
uv run --group report python make_report_pdf.py
```

Нужен Arial (Windows) или DejaVu Sans (Linux); для другой системы задайте `REPORT_FONT` и `REPORT_FONT_BOLD`. [Отдельные результаты ноутбука](week2/practice/LIVE_VALIDATION.md) включают разбор случая, где модель перепутала число конкурентов с расстоянием.
